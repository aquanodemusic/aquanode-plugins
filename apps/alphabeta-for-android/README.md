# AlphaBetaSynth

This is the Android Version of my AlphaBeta Synth. For more details, please refer to the readme file in the /synths directory!

AlphaBeta is a virtual analog synthesizer closely modelled after the Free LinPlug Alpha 3 VST synthesizer that is not maintained anymore.
You can load original presets as well! It has a native mode (own implemenation) and an original mode (closely measured how the original synth sounds and carried over to my own code). Made with the help of Claude Opus 5.5 by Anthropic.
