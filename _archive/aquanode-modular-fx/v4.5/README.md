# Aquanode Modular FX Version

This is the source code for the FX version of Aquanode Modular.
All documentation for it can be found in the synth version directory.

**Aquanode Modular** is a free modular synthesizer with tons of modules for creative sound design.

You can easily place modules, drag patch cables, and sculpt complex sounds out of simple building blocks.
For Aquanode FX to work, you need to add an Audio In Module from the Sidebar and route its output socket
into the FX patches of your choice, and then into an Audio Out Module at the end.

Click on Initialize Patch for getting the Audio In -> Audio Out modules directly.

Have fun!
