# Granulate FX

Granulate FX is the FX version of the Granulate Synthesizer/Sample Player VST.
Instead of loading a sound file, it sits on a mixer track and tracks incoming audio.
You can choose how long the time window should be that is automatically cycled through using a ring buffer.
The grains now sit in place relative to the incoming audio.
Naturally, there are no note controls anymore, but the rest works like in the Synth version.

For more information about the controls please have a look at said Synth Version. Thanks for trying it out!
